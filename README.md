# Iris Classification & Explainable AI

An academic machine learning project exploring Iris flower
classification, dimensionality reduction, and model explainability.

## Project Overview

This project explores:
- Iris dataset preprocessing and visualization
- Random Forest classification
- Kernel PCA for dimensionality reduction
- LIME explanations for individual predictions
- SHAP-based model interpretation

## Technologies

Python, pandas, NumPy, scikit-learn, Matplotlib,
LIME, SHAP, Jupyter Notebook.

## Repository Structure

- `notebooks/` — analysis notebook
- `data/` — dataset file, when included
- `requirements.txt` — Python dependencies

## How to Run

1. Install the dependencies:
   `pip install -r requirements.txt`
2. Open the notebook in Jupyter or Google Colab.
3. If using `iris.xlsx`, ensure the notebook's file path
   points to `data/iris.xlsx`.
4. Run the notebook cells in order.

## Notes

The notebook demonstrates model interpretation with
LIME and SHAP. It is an academic learning project;
results should be interpreted in the context of
the dataset and evaluation methodology.
